# 🚀 Future Improvements

Possíveis melhorias para implementar após a conclusão da versão inicial do projeto.

## 🔐 Streamlit Authentication

Adicionar autenticação de usuários para controlar o acesso ao sistema.

Possíveis funcionalidades:

- Tela de login
- Logout
- Identificação do usuário logado
- Restrição de acesso ao sistema
- Diferentes níveis de acesso
  - Administrador
  - Vendedor
- Exibir o usuário autenticado na interface

## ✏️ Editar vendas

Adicionar a possibilidade de pesquisar uma venda pelo ID e editar seus dados.

Possíveis funcionalidades:

- Campo para informar o ID da venda
- Buscar a venda cadastrada
- Carregar os dados atuais no formulário
- Alterar as informações
- Salvar as alterações na base de dados
